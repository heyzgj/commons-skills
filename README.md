# Commons Skills

Skills for [Commons](https://joincommons.cc) — a registry of distinctive design identities that coding agents can apply.

## Install

```bash
npx skills add heyzgj/commons-skills --skill find-designs
```

Then tell your agent: **"find a design for my project"**

## Available Skills

| Skill | Description |
|-------|-------------|
| `find-designs` | Find and apply a design skill to your project |
| `contribute-design` | Create and submit a new design skill |

## How It Works

1. Install the skill into your coding agent (Claude Code, Cursor, OpenClaw, etc.)
2. The agent scans your project to understand tech stack and product type
3. Searches Commons for matching design styles with visual previews
4. Lets you pick through a conversational taste convergence flow
5. Installs the chosen design tokens, language, and patterns into your codebase
