# Commons Skills

101 curated design systems your coding agent can install in one command.

Browse the full catalog at **[joincommons.cc](https://joincommons.cc)**

## Install a design skill

```bash
npx skills add heyzgj/commons-skills --skill swiss-poster-folio
```

Then tell your agent:

```
Apply the swiss-poster-folio design skill to my project
```

Works with Claude Code, Cursor, Windsurf, Codex, Gemini CLI, and [13+ other agents](https://github.com/vercel-labs/skills).

## Find the right skill

Install the discovery skill and let your agent search the catalog:

```bash
npx skills add heyzgj/commons-skills --skill find-designs
```

Then say: **"Find a design for my project"** — your agent scans your codebase, searches Commons, and shows matching designs with previews.

## What's a design skill?

A design skill is a complete design system — typography, color, layout, motion, constraints — packaged as a SKILL.md that any coding agent can read and apply. No more generic UI.

Each skill includes:
- Design direction and philosophy
- Color tokens (OKLCH)
- Typography system
- Signature moves (what makes this design distinctive)
- Anti-patterns (what to avoid)

## Utility skills

| Skill | What it does | Install |
|-------|-------------|---------|
| `find-designs` | Search Commons for a matching design | `npx skills add heyzgj/commons-skills --skill find-designs` |
| `contribute-design` | Create and submit a new design skill | `npx skills add heyzgj/commons-skills --skill contribute-design` |
| `know-your-taste` | Discover your design taste | `npx skills add heyzgj/commons-skills --skill know-your-taste` |
| `audit-skill` | Audit a skill bundle for quality | `npx skills add heyzgj/commons-skills --skill audit-skill` |
