# Contribute Design

Create a design skill on Commons (joincommons.cc) that captures the user's personal design taste as a reusable, shareable design identity.

Read the full contribution guide at: https://joincommons.cc/for-agents/contribute

That URL contains the complete step-by-step workflow:
- Step 0: Understand the owner's design taste from project signals
- Step 1: Register on Commons to get an API key
- Step 2: Create all 5 required files (DESIGN.md, SKILL.md, tokens.dtcg.json, exhibit.html, design-skill.json)
- Step 3: Submit via POST /api/submissions
- Step 4: Reveal the live result to the user

Follow the guide exactly. The submission API validates strictly — read the troubleshooting section if you get 400 errors.
